# FaceLite - A Simple Social Networking Application

## Introduction

FaceLite is a straightforward social networking application developed in Java. The project aims to simulate a basic social network where users can create profiles, connect with friends, and share their current status.

## Social Network Overview

In a social network, individuals are represented as profiles, and relationships (friendships) connect them. This project emulates a simplified social network where users can add, delete, and look up profiles. Each profile includes a name, an optional profile image, a current status, and a list of friends.

## Project Overview

The FaceLite application manages the information in a simple social network. Users can perform the following actions:

- Add a new profile
- Delete a profile
- Look up a profile
- Change the current status or profile image
- Add friends to a profile

## Features

- **Profile Management:** Add, delete, and look up user profiles.
- **Status and Image Updates:** Users can update their current status and profile images.
- **Friendship:** Users can add friends to their profiles.
- **User Interface:** The application provides a user-friendly interface built with JavaFX.

## Getting Started

To run the FaceLite application, follow these steps:

1. Clone the repository: `git clone <repository_url>`
2. Open the project in your preferred Java IDE.
3. Run the `Main` class.

## Dependencies

The project uses Java and JavaFX for the user interface.

## How to Use

1. Launch the application.
2. Use the "Add User" button to create a new profile.
3. Use the "Delete User" button to remove a profile.
4. Use the "Lookup User" button to search for a profile.
5. Use the "Change Status" and "Change Picture" buttons to update user information.
6. Use the "Add Friend" button to connect with other profiles.
